◆ rawConeInteriorPoint()

MutableMatrix * rawConeInteriorPoint ( const Matrix *  A)

For the cone { x in QQ^n : A * x <= 0 }, runs a single linear program (GLPK, double precision) that simultaneously decides full-dimensionality and produces either an interior witness or a Farkas-style dual certificate of non-full-dimensionality. The implementation negates A because the helper coneInteriorPoint() works with {x : A x >= 0}.

The LP
With the cone being A x <= 0, the LP is:
maximize t
subject to A_i * x <= -t for each row i = 1, ..., m
-1 <= x_j <= 1 for j = 1, ..., n (normalization)
t >= 0
t is the strict-feasibility margin. If the optimum tStar > 0 (with numerical tolerance 1e-8), the cone is full-dimensional and the primal x is an interior witness (each A_i x < 0 strictly). If tStar <= 0 the cone is not full-dimensional, and the row duals supply a non-negative y >= 0 with y^T A = 0. The [-1, 1] box on x keeps the LP bounded; without it t could scale to infinity along any interior ray.
Parameters
AAn m-by-n matrix over ZZ; each row is one inequality. Entries must fit in a C int.
Returns
A 1-row dense MutableMatrix over RR(53):
  • Full-dimensional (tStar > 0): 2 + n columns, [1, tStar, x_1, ..., x_n].
  • Not full-dimensional (tStar <= 0): 2 + m columns, [0, tStar, y_1, ..., y_m] where y >= 0 and y^T A = 0.

Returns nullptr on error (entry of A overflows C int, or engine error).

Example (M2 top level)
debug Core
-- Full-dimensional: first octant in QQ^3
A = matrix {{-1,0,0},{0,-1,0},{0,0,-1}}
map(RR_53, rawConeInteriorPoint raw A)
-- | 1 1 1 1 1 | -- flag=1, tStar=1, interior=(1,1,1)
-- Not full-dimensional: the positive y-axis in QQ^2
A = matrix {{1,0},{-1,0},{0,-1}}
map(RR_53, rawConeInteriorPoint raw A)
-- | 0 0 .5 .5 0 | -- flag=0, tStar=0, dualCert=(.5,.5,0)
In the second example the certificate (0.5, 0.5, 0) gives 0.5*(1,0) + 0.5*(-1,0) + 0*(0,-1) = (0,0), witnessing that the inequalities x <= 0 and -x <= 0 collapse the cone to the line x = 0.
